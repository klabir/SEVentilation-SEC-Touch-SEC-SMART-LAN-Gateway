# SEC Smart Ventilation v0.4.0

v0.4.0 adds an opt-in expiry timer for Schedule overrides and expands Home
Assistant-owned scheduling with adaptive ventilation Blueprints.

## Highlights

- Configure a 0–1440 minute Schedule-override timeout independently for each
  room. Positive deadlines persist in UTC across reloads and restarts; repeated
  activation renews the period.
- Use the optional Free Cooling or absolute-humidity schedule overlay with
  hysteresis, minimum dwell time, sensor/cloud safety gates, duplicate command
  suppression, and return to the active Schedule block.
- Import all three scheduling Blueprints directly from the README.
- Validate override behavior in a dedicated Home Assistant 2026.10.2 lifecycle
  CI lane (5 lifecycle tests), alongside 21 lightweight tests.

## Update

In HACS, download v0.4.0 and restart Home Assistant Core once. Existing config
entries, automations, integration options, and device/vendor timers are
preserved. No `.storage` editing or reconfiguration is required.

The timeout defaults to `0`, including for migrated installations, so no
automatic expiry is enabled by the update. An existing restored override that
is on remains indefinite until a positive timeout is configured or the switch
is turned off.

## Set an override timer

Enable **Allow ventilation control** in the integration's **Configure** dialog,
then open the SEC Smart device for the room. Set **Schedule override timeout**
to a positive number of minutes and turn on **Schedule override**. Changing a
positive timeout while the override is on restarts the countdown; turning the
override off cancels it; `0` keeps it on indefinitely.

Expiry only turns off the local override switch. It does not send a fan command;
the selected scheduling Blueprint normally restores control on its next
five-minute reconciliation or block boundary.

## Known limits

- Initial integration startup still requires a successful SEC cloud refresh.
  After startup, the local override controls remain available during a later
  cloud outage.
- The SEC cloud API remains unofficial and may change. SEC-Touch and the vendor
  app remain the fallback.
- The adaptive Blueprints supplement, but do not replace, SEC hardware frost,
  condensation, or building-protection logic.

See the [README](https://github.com/klabir/SEVentilation-SEC-Touch-SEC-SMART-LAN-Gateway/blob/v0.4.0/README.md)
for setup, timer semantics, Blueprint safety behavior, and rollback instructions.
